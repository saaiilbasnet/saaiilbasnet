## About Me

I’m a **Junior Backend Developer** focused on building reliable, maintainable, and scalable web applications.

My primary experience is in **Node.js, NestJS, Express.js, PostgreSQL, and REST API development**. I enjoy designing backend architecture, building APIs, working with relational databases, implementing authentication and authorization, and turning application requirements into clean backend systems.

I’m particularly interested in **backend architecture, database design, API development, and scalable web applications**.
